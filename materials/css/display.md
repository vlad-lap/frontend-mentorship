# CSS Display

Display is a CSS property that determines how an element is displayed on the page. It can be used to control the layout and visibility of elements. The following are some common values for the `display` property:

1. `display: none` - element is not displayed and does not take up space in the layout.
2. `display: block` - element is displayed as a block, takes up the full width, and starts on a new line.
3. `display: inline` - element is displayed as inline, takes up only the necessary space, and does not start on a new line.
4. `display: inline-block` - element is displayed as inline, but can have dimensions and margins like a block.
5. `display: contents` - element is not displayed, but its child elements are displayed as if they were direct children of its parent.
